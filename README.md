# AURA LUXE — Premium Fashion Experience & Business Management Platform

AURA LUXE is a premium, high-performance D2C clothing-commerce storefront and business operating platform built with React, TypeScript, Tailwind CSS, and Vite.

## ✨ Key Features

### 🛍️ Customer Storefront
- **Fashion Campaign Homepage**: Full-bleed hero banners, new arrival rails, Mood Tiles (`AFTER DARK`, `STREET`, `MINIMAL`, `RESORT`), split editorial section (*The Weekend Edit*), and interactive hotspot-based "Shop the Look".
- **Advanced Catalog (PLP)**: Alternate image hover swap, mobile bottom-sheet filters, and responsive product grids.
- **Product Detail Experience (PDP)**: Size selector, **Fit Confidence Score (91%)**, **Product Versatility Personalities** switcher (*Minimal*, *Office*, *Street*, *Date Night*), Wardrobe duplicate warnings, and care instructions.
- **Shopping Brief & "BUY THE LOOK"**: Natural-language outfit styling assistant based on occasion and dress code requirements.
- **Style DNA Profiler**: Interactive visual quiz formulating personalized style archetypes.
- **Personal Wardrobe Vault**: Customer clothing vault with automated *"WORKS WITH YOUR WARDROBE"* pairing suggestions.
- **Look Engine & Remix Studio**: Dynamic outfit builder with 1-click **REMIX** variation generator.

### 📊 STORE PULSE (Business Management Platform)
- **Actionable Signal Cards**: Operational dashboard highlighting low-stock alerts, high return rate warnings, and top sales velocity trends.
- **Visual Inventory Health**: Real-time breakdown of fast movers, low stock items, overstocked inventory, and out-of-stock SKUs.
- **Connected State Engine**: Real-time synchronization between order placements, inventory deductions, customer CRM tiers, and owner revenue statistics.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/singh-105/web.git

# Navigate into project directory
cd web

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
```

## 🛠️ Tech Stack
- **Framework**: React 18 / TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Charts**: Recharts
